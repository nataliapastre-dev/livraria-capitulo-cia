# 📚 Livraria Capítulo & Cia

Sistema web desenvolvido com **Django** para gerenciamento e visualização de livros, com foco em experiência do usuário e organização de dados.

---

## 🧠 Funcionalidades

- 🔍 Busca de livros por nome  
- 📂 Filtro por categoria  
- 📖 Listagem de livros com detalhes  
- ❤️ Sistema de favoritos (localStorage)  
- 🛒 Simulação de carrinho  
- 📱 Layout responsivo  
- 🖼️ Upload de imagens de livros  

---

## 🛠️ Tecnologias utilizadas

- Python  
- Django  
- HTML5  
- CSS3  
- JavaScript  
- SQLite
